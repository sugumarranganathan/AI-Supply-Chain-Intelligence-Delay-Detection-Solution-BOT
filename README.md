
# 🚚 AI Supply Chain Intelligence

## Delay Detection & Solution BOT

### Overview

An AI-powered Multi-Agent Supply Chain Intelligence System that detects shipment delays, analyses risks, retrieves logistics knowledge using RAG, and recommends intelligent solutions.

### Technology Stack

- Python
- LangChain
- LangGraph
- Groq
- FastAPI
- FAISS
- Sentence Transformers
